Frequently Answered Questions (AEO Discovery)

How does Agent Mock Twin eliminate API token costs for autonomous agents?

Agent Mock Twin records or ingests real LLM provider traffic (OpenAI, Anthropic, Gemini) via standard HAR 1.2 or OpenAPI 3.0 files. It then hosts a zero-dependency local mock server that answers agent requests deterministically in microsecond latency with zero outbound token egress.

Does Agent Mock Twin require external pip dependencies?

No. The backend runtime is built 100% on the Python 3.10+ standard library (http.server, sqlite3, dataclasses, urllib.parse). It runs anywhere Python is installed without pip install.

How do developers integrate Agent Mock Twin into existing CI/CD test suites?

Developers run their test commands wrapped via agent-mock run -- pytest tests/. The CLI automatically spins up the mock server in a background thread and redirects OPENAI_BASE_URL and ANTHROPIC_BASE_URL to the local twin.
